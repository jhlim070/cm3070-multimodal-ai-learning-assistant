// Recursive function to search for x in arr[]
int searchElement (int arr[], int size, int x) {
      
    size--;
    cout <<" " << arr[size];  
    // Base case (Element not present in the array)
    if (size < 0) { // stop
        return -1;
    }
    // Base case (Element found, return its position)
    if (arr[size] == x) { // stop
        return size;
    }
  
    // Recursive case
    return searchElement (arr, size, x);
  
}

14What is Big O  O(n^2) ?   e.g. {3,2,1}   n^2 = 3^2 = 9 iterations
Big O describes the upper bound of an algorithm.
Using our Insertion Sort example, the rate of growth of our 
algorithm is at most quadratic, or O(n^2). Worst -Case scenario
What is Big Omega Ω(n) ?     e.g. {1,2,3} n = 3 iterations
Big Omega describes the lower bound of an algorithm.
Using our Insertion Sort example, if the input is already 
sorted , then the rate of growth of our algorithm is at 
least linear, or Ω(n).
We can also think of this as our best -case scenario.
What is Big Theta   Θ(n) or θ(n) ? n^2 = 3^2 = 9 iterations
Using our Insertion Sort example, we know that the rate of growth 
isat most O(n^2) and at least Ω(n).
Big Theta is often used to describe the average, or expected, case for 
an algorithm. So for Insertion Sort, the average case  for Big Theta 
isn^2.
