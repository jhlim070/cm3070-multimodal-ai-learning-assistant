Automated Testing

As your codebase expands, small errors and edge cases you don’t expect can cascade into larger failures. 

Bugs lead to bad user experience and ultimately, business losses. 

One way to prevent fragile programming is to test your code before releasing it into the wild.

B

Automated Testing

Why Test?

We're humans, and humans make mistakes. 

Testing is important because it helps you uncover these mistakes and verifies that your code is working. 

Perhaps even more importantly, testing ensures that your code continues to work in the future as you add new features, refactor the existing ones, or upgrade major dependencies of your project.

B

Automated Testing

Why Test?

Tests can also serve as documentation for new people joining your team. For people who have never seen a codebase before, reading tests can help them understand how the existing code works.

Last but not least, more automated testing means less time spent with manual QA, freeing up valuable time.

B

Automated Testing

The primary types of tests are:

Unit Tests: Unit testing ensures that each part of the code delivers the desired output. 

Developers only look at the interface and the specifications of the components. 

Thorough standalone testing of each component is performed before moving on to the next unit.

B

Automated Testing

The primary types of tests are:

Component Tests: Component testing is performed to verify the functionality and/or usability of a component, but it is not restricted to only these.

Components can be anything that can take input(s) and deliver some output – for example, a code module, a web page, a screen and even a system inside a larger system.

B

Automated Testing

The primary types of tests are:

Integration Tests: Integration testing is performed to test individual components to check how they function together. 

It involves testing the integration between modules that are working fine individually. 

Integration testing provides clarity about the overall functionality of the application.

Jest is a testing framework built using JavaScript and maintained by Facebook. Facebook itself uses the Jest testing framework to test their own React Native apps.

For React Native version 0.38 and above, Jest is included when you create a new project, so the following setup may already be completed for you.

Syntax Transformer

Syntax transformers in React Native enable the use of advanced JavaScript syntax or language features not supported by default JavaScript engines.

Examples that default Javascript engines does not support:
ECMAScript Modules: The ability to use import and export statements for module loading and exporting.

// Module.js
export function sayHello() {
  console.log('Hello!');
}

// App.js
import { sayHello } from './Module';

B

Syntax Transformer

Examples that default Javascript engines does not support:
JSX: JSX is a syntax extension for JavaScript that allows you to write HTML-like code in your React components.

import React from 'react';

function MyComponent() {
  return (
    <div>
      <h1>Hello, React!</h1>
    </div>
  );
}

B

Syntax Transformer

Examples that default Javascript engines does not support:
Arrow Functions: Arrow functions provide a concise syntax for writing anonymous functions. While arrow functions are widely supported, older JavaScript engines may not have full support for them.

const add = (a, b) => a + b;
console.log(add(2, 3)); // Output: 5

B

Syntax Transformer

Examples that default Javascript engines does not support:
Object and Array Destructuring: Destructuring allows you to extract values from objects or arrays into individual variables. It is a convenient syntax that may not be supported by default in older JavaScript engines.

const person = { name: 'John Doe', age: 25 };
const { name, age } = person;
console.log(name, age); // Output: John Doe 25

const numbers = [1, 2, 3, 4, 5];
const [first, second, ...rest] = numbers;
console.log(first, second, rest); // Output: 1 2 [3, 4, 5]

B

Syntax Transformer

Presets like @babel/preset-env and @babel/preset-react enable transformation of modern JavaScript and JSX syntax, respectively.

Plugins like @babel/plugin-transform-runtime enable advanced features requiring runtime support.

Note:
React Native's default Babel configuration already includes essential transformations.

B

Syntax Transformer

Babel is a popular syntax transformer used in React Native.

Babel transforms modern JavaScript features into compatible code understood by JavaScript engines.

To use Babel as a syntax transformer:
Set up a configuration file (e.g., .babelrc or babel.config.js) in the project's root directory.
Specify presets and plugins in the configuration file to transform the code.
